# 김태현 · 웹 포트폴리오

웹·모바일 개발 경력과 프로젝트를 소개하는 Next.js 포트폴리오입니다.

**Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion**

## 개발

```bash
npm ci
npm run dev
```

검사·빌드: `npm run lint`, `npm run build`

`src/app/`에 소개·프로젝트 페이지, `src/components/`에 공통 화면 요소, `public/`에 이미지가 있습니다.

최신 프로젝트 목록과 역할은 [개발 포트폴리오](https://github.com/kimth1113/portfolio)에 함께 정리했습니다. 교육 프로젝트·업무 개발·개인 앱 운영을 구분합니다.
