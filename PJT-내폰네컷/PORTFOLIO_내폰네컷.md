# 내폰네컷

## AI 기반 모바일 포토부스 앱

**개발 기간** | 2026.01 ~ 2026.02 (1개월)
**플랫폼** | iOS / Android (React Native)
**역할** | 1인 풀스택 개발

---

## 프로젝트 개요

스마트폰에서 AI로 배경을 제거하고, 감성 문구를 생성하며, 프레임을 꾸밀 수 있는 **모바일 포토부스 앱**입니다.

### 기획 배경

| 기존 포토부스의 한계     | 내폰네컷의 해결책        |
|:--------------- |:---------------- |
| 주말 30분 대기       | 언제 어디서나 즉시 촬영    |
| 회당 4,000~6,000원 | 무료 (광고 기반)       |
| 고정된 배경 선택지      | AI 배경 제거 + 무한 색상 |
| 문구는 직접 고민       | AI가 상황에 맞게 생성    |
| 한 번 찍으면 수정 불가   | 무한 재촬영, 무한 편집    |

---

## 핵심 기능

### 1. AI 배경 제거 & 합성

- **BiRefNet** 모델로 머리카락까지 정교하게 분리
- 원하는 배경색으로 실시간 합성
- 배치 처리로 4장 동시 처리

### 2. AI 문구 생성

- **Claude API** 기반 상황 맞춤 문구
- 3가지 모드: SNS 드립 / 감성 편지 / 블랙 코미디
- 사진 분석 → 관계 파악 → 5개 후보 생성

### 3. AI 톤 변환

- **Flux-Kontext** 모델로 스타일 변환
- 흑백 드로잉 / 애니메이션 스타일

### 4. 프레임 & 다국어

- 시즌별 프레임, 기념일 캘린더
- 11개 언어 지원 (한/영/중/일 등)

## 기술 스택

### Frontend

| 기술                      | 선택 이유                        |
|:----------------------- |:---------------------------- |
| **React Native + Expo** | iOS/Android 동시 개발, 빠른 프로토타이핑 |
| **TypeScript**          | 타입 안정성, 개발 생산성               |
| **React Navigation v7** | 네이티브 수준 네비게이션                |
| **FFmpeg**              | 영상 편집 기능 확장성                 |

### Backend

| 기술                        | 선택 이유                       |
|:------------------------- |:--------------------------- |
| **Django REST Framework** | 빠른 API 개발, Python AI 생태계 연동 |
| **Replicate API**         | GPU 서버 없이 AI 모델 사용          |
| **Claude API**            | 고품질 한국어 문구 생성               |

### 성능 최적화 포인트

| 문제                  | 해결책                | 결과             |
|:------------------- |:------------------ |:-------------- |
| 배경 제거 3초 × 4장 = 12초 | 서버 병렬 처리 (동시성 2)   | **6초로 단축**     |
| 색상 변경마다 GPU 재호출     | 전경 PNG 캐싱 → CPU 합성 | **3초 → 5ms**   |
| 대용량 이미지 업로드         | 768px 리사이징 후 전송    | **트래픽 70% 감소** |
| Replicate 429 에러    | 지수 백오프 재시도 (12회)   | **안정성 확보**     |

## 성과 & 배운 점

### 기술적 성과

- AI API 비용 최적화 (캐싱으로 GPU 호출 80% 감소)
- 배치 처리 아키텍처 설계 및 구현
- 11개 언어 i18n 시스템 구축

### 배운 점

- **외부 API 의존성 관리**: Rate Limit, 에러 핸들링, 폴백 전략
- **UX 중심 최적화**: 체감 속도 개선을 위한 캐싱 설계
- **모노레포 구조**: apps/mobile + server 통합 관리
