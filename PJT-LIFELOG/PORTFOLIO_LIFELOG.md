# LIFELOG - AI 기반 포토부스 경험 플랫폼

> **EST 주관 AI 프로젝트 우수작** | Live Demo: [체험하기](https://d3e5arjoobi964.cloudfront.net/)

## Project Summary

**"사진만 남는 포토부스"를 "기억까지 남는 포토부스"로**

LIFELOG는 촬영 순간의 날짜, 위치, 날씨, 감정을 함께 기록하고, AI가 맥락 기반 문구와 해시태그를 생성해 출력물로 완성하는 키오스크형 서비스입니다.

![메인 화면](docs/readme-images/image-20260114131254284.png)

**개발 기간** | 2026.01 ~ 2026.02 (1개월) 

**플랫폼** | 웹(React + 장고)

**역할** | 1인 풀스택 개발

---

## Core Features

### 1. GPT 멀티모달 기반 문구 생성

| 입력 요소 | 설명                |
| ----- | ----------------- |
| 사진 분석 | 인물 구도, 표정, 장면 분위기 |
| 메타데이터 | 날짜, 위치, 날씨, 관계/모드 |

사진과 맥락 정보를 결합해 **"그 순간을 설명하는 한 줄 문장"**을 생성합니다.
같은 사진이라도 선택한 모드에 따라 결과 톤이 달라집니다.

![문구 생성 예시](docs/readme-images/image-20260114133424356.png)

### 2. 관계·위치 기반 해시태그 자동 생성

- **관계 기반**: 커플, 친구, 가족 등 선택한 관계에 맞는 톤의 해시태그 6개 추천
- **위치 기반**: 동네 분위기, 랜드마크, 상권 맥락을 반영한 지역 해시태그 생성

| 관계  | 해시태그 예시                               |
| --- | ------------------------------------- |
| 커플  | #CoupleShot #데이트기록 #오늘의우리 #LoveMoment |
| 친구  | #Besties #친구랑찰칵 #추억저장 #한장더            |
| 가족  | #FamilyTime #가족사진 #함께한순간 #기념샷         |

## Tech Stack

![기술 구성도](docs/readme-images/image-20260114134512742.png)

| Layer        | Technology               | 역할                       |
| ------------ | ------------------------ | ------------------------ |
| **Frontend** | React + Vite             | 키오스크 최적화 대화면 UI, 촬영 플로우  |
| **Backend**  | Django + DRF             | AI 요청 오케스트레이션, 업로드/결과 관리 |
| **AI**       | OpenAI GPT-4 Vision      | 사진 분석 및 문구/해시태그 생성       |
| **Infra**    | AWS (S3, CloudFront, EB) | 정적 배포, CDN, API 서버 운영    |

---

## Architecture

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Frontend  │────▶│   Backend   │────▶│  OpenAI API │
│  (React/S3) │     │  (Django/EB)│     │ (GPT-4 Vision)
└─────────────┘     └──────┬──────┘     └─────────────┘
                           │
                    ┌──────▼──────┐
                    │   AWS S3    │
                    │ (사진/결과물) │
                    └─────────────┘
```

**배포 구성**

- **Frontend**: S3 + CloudFront 정적 배포 (글로벌 캐싱)
- **Backend**: Elastic Beanstalk API 서버
- **Storage**: S3 (촬영 사진, 생성 문구, 메타데이터)
