## 2. 기술 스택

### Frontend (키오스크 UI)
```
React.js / TypeScript
Electron (데스크톱 앱 패키징)

27인치 터치스크린 최적화 UI
```

### Backend (서버)
```
Node.js / Express
Python Flask (AI 모델 서빙)
REST API 설계
SQLite / PostgreSQL
```

### AI / Machine Learning
```
TensorFlow / Keras
Google Teachable Machine (프로토타입)
CNN 기반 이미지 분류 모델
COCO 형식 객체 탐지 (바운딩박스)
```

### Hardware Integration
```
로드셀 무게 센서 연동
근접 센서 (상하 이중 감지)
모터 제어 API
카메라 모듈 연동
```

## 3. 주요 개발 내용

### 3.1 프론트엔드 - 키오스크 UI 개발

#### 사용자 인터페이스 설계
- **27인치 터치스크린** 최적화 레이아웃
- 직관적인 전선 투입 가이드 화면
- 실시간 AI 분석 결과 시각화
- 리워드 적립 현황 대시보드

#### 주요 화면 구성
| 화면 | 기능 |
|------|------|
| 메인 화면 | 서비스 소개, 전선 투입 유도 |
| 분석 화면 | AI 분석 진행 상태, 실시간 카메라 뷰 |
| 결과 화면 | 전선 종류, 무게, 예상 리워드 표시 |
| 완료 화면 | 적립 완료, QR코드 리워드 지급 |

#### 기술적 특징
- **반응형 터치 인터랙션**: 대형 버튼, 스와이프 제스처 지원
- **접근성 고려**: 고대비 색상, 큰 폰트 사이즈
- **애니메이션**: 분석 중 로딩 애니메이션, 결과 트랜지션

---

### 3.2 백엔드 - 서버 개발

#### API 설계
```
POST /api/analyze      - 전선 이미지 분석 요청
GET  /api/result/:id   - 분석 결과 조회
POST /api/reward       - 리워드 적립 처리
GET  /api/statistics   - 수거 통계 데이터
POST /api/sensor       - 센서 데이터 수신
```

#### 하드웨어 통합
- **센서 데이터 처리**: 근접 센서, 로드셀 무게 센서 실시간 모니터링
- **모터 제어**: 수거판 회전, 분류 게이트 개폐 명령 전송
- **카메라 연동**: 실시간 영상 스트리밍 및 캡처

#### 데이터 관리
- 전선 분류 이력 저장 및 통계 분석
- 사용자 리워드 트랜잭션 관리
- 기기별 운영 상태 모니터링

---

### 3.3 AI 모델 - 전선 분류 시스템

#### 학습 데이터셋 구축
| 그룹 | 분류 항목 | 데이터 수량 |
|------|----------|------------|
| 그룹1 | 기본 전선 8종 (VCTF, HIV 등) | 1,000+ 이미지 |
| 그룹2 | 랜선 2종, 멀티콘센트 | 500+ 이미지 |
| 그룹3 | AUX, USB, 마우스, 모니터, 전원 케이블 | 2,000+ 이미지 |

#### 데이터 어노테이션
```json
{
  "shapes": [{
    "label": "covering_PVC",
    "points": [[539.14, 684.44], [440.71, 726.78], ...]
  }]
}
```
- **Polygon 어노테이션**: 전선 외피 영역 정밀 마킹
- **바운딩박스**: 객체 탐지용 COCO 형식 라벨링
- **총 수천 개** 이미지 라벨링 완료

#### 모델 아키텍처
```
Input Layer (224x224x3)
    ↓
CNN Feature Extraction
    ↓
Global Average Pooling
    ↓
Dense Layer (256 units, ReLU)
    ↓
Output Layer (15 classes, Softmax)
```

#### 성능 지표
| 지표 | 수치 |
|------|------|
| 분류 정확도 | 90%+ |
| 추론 시간 | < 500ms |
| 지원 전선 종류 | 15종 |

## 5. 주요 기능 및 구현 상세

### 실시간 전선 분석 플로우
```
1. 사용자 전선 투입 → 근접 센서 감지
2. 카메라 자동 촬영 → 이미지 캡처
3. AI 모델 추론 → 전선 종류 판별
4. 로드셀 측정 → 무게 데이터 수집
5. 결과 통합 → 리워드 계산
6. UI 결과 표시 → 사용자 확인
7. 모터 구동 → 해당 수거통 분류
```

### 지원 전선 종류 (15종)
| 카테고리 | 세부 종류 |
|---------|----------|
| 기본 전선 | VCTF 0.75sq, VCTF 1.5sq, HIV, 동축 케이블 등 8종 |
| 데이터 케이블 | 랜선 CAT5e, CAT6, USB 3.0 |
| 주변기기 | 마우스 케이블, 키보드 케이블 |
| 영상/음향 | AUX 케이블, 모니터 연결 케이블 |
| 전원 | AC 전원 케이블, 멀티콘센트 |
