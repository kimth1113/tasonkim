# InBody 사양관리 웹사이트

## 프로젝트 개요

**개발 기간:** 2021년 11월
**역할:** 풀스택 개발
**기술 스택:** React (TypeScript), .NET 5.0, MSSQL, Azure (Blob Storage, Table Storage)

영업관리팀의 인바디 장비 사양 관리를 **오프라인에서 온라인으로 전환**하여 업무 효율을 획기적으로 개선한 B2B 내부 시스템입니다.

### 해결한 문제
| 기존 방식 | 개선된 방식 |
|-----------|-------------|
| USB를 통한 오프라인 사양 변경 | 웹 기반 실시간 사양 승인 |
| 담당 영업사원 방문 필요 (2~3일 소요) | 즉시 원격 처리 가능 |
| 시간/공간 제약 발생 | 언제 어디서나 접속 가능 |

---

## 핵심 기능

### 1. 장비 현황 관리
- ERP 시스템과 API 연동을 통한 **실시간 장비 리스트 조회**
- 다양한 검색 조건(모델, 지역, 구매처 등)으로 필터링
- 페이지네이션을 통한 대용량 데이터 처리 (20개/페이지)

### 2. 사양 변경 승인 시스템
- **LB웹과 실시간 API 통신**으로 장비 사양 원격 변경
- 모달 기반 승인 워크플로우로 실수 방지
- 오프라인 장비 대비 **QR코드 자동 생성 및 이메일 발송**

### 3. 보안 및 로깅
- Microsoft Azure AD 통합 계정 로그인
- 모든 유저 활동 **Azure Table Storage에 로그 기록**
  - 조회/승인/수정 등 액션별 기록
  - IP 주소, URL, 타임스탬프 추적

## 기술적 구현 사항

### Frontend (React + TypeScript)
- **Redux**를 활용한 전역 상태 관리
  - 검색 조건, 장비 리스트 상태 분리 관리
  - 컴포넌트 간 복잡한 데이터 통신 해결
- **컴포넌트 구조화**: Page → Component → ViewParts 계층 분리
- **다국어 처리 (i18n)** 적용으로 글로벌 확장성 확보

### Backend (.NET 5.0)
- **RESTful API** 설계 및 구현
- **Stored Procedure** 기반 데이터 처리로 성능 최적화
- **ZXing.NET**을 활용한 QR코드 생성
- **SMTP 메일 발송** 시스템 구현

### Database & Cloud
- **MSSQL** 3개 DB 연동 (ERP, LB웹, 자체 DB)
- **Azure Blob Storage**: QR코드 이미지 중앙 저장소
- **Azure Table Storage**: 유저 활동 로그 저장

## 주요 성과

- 사양 변경 처리 시간 **2~3일 → 즉시 처리**로 단축
- 담당 영업사원 방문 비용 절감
- 모든 사양 변경 이력 **중앙 집중 관리** 체계 구축
- 오프라인/온라인 장비 모두 대응 가능한 **하이브리드 솔루션** 구현
